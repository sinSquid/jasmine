# 项目工作流程

- 开始工作前必须阅读并遵守 `团队与AI Coding项目规范.md`；涉及人员与 AI 的沟通和授权时，同时参考 `团队成员研发执行规范.md`。
- 修改团队规范时，必须检查两份规范之间是否存在矛盾、重复或人员责任不一致。

## Git 推送门禁

- 只有在用户当前请求中明确要求执行 `push` 或“推送”时，才允许执行 Git 推送；修改、测试和提交均不构成隐含的推送授权。
- 改动必须先推送到功能或修复分支，再通过 Merge Request（MR）合入 `main` 或 `master`。
- 禁止直接向 `main` 或 `master` 推送；用户要求直接推送主分支时，必须停止并说明应改为通过 MR 合入。
